# Contributing to Awesome Proxy Ecosystem

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## How to Contribute

### 1. Adding a New Protocol or Tool

When adding a new entry, please include:
- **Name** — The official name of the protocol/tool
- **GitHub URL** — Link to the primary repository
- **Description** — Brief description of what it does
- **Status** — Active (✅), Archived (⚠️), or Deprecated (❌)
- **Platform** — Supported platforms

### 2. Updating Existing Entries

- Verify links are still working
- Update status if a project has been archived
- Add new features or capabilities

### 3. Translating Documentation

We welcome translations! To add a new language:
1. Create a new directory under `docs/<language-code>/`
2. Translate the README.md
3. Update the language switcher in all README files

Current supported languages:
- `en` (root README.md)
- `zh-CN` — 简体中文
- `ja` — 日本語
- `ko` — 한국어

### 4. Reporting Issues

If you find:
- Broken links
- Outdated information
- Missing important projects
- Errors in descriptions

Please open an issue with:
- The problematic entry
- Suggested correction
- Source/reference for the correction

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/add-new-protocol`)
3. Make your changes
4. Ensure all links are valid
5. Commit with a clear message
6. Open a Pull Request

## Code of Conduct

- Be respectful and constructive
- Focus on technical merit
- No promotion of illegal activities
- Keep discussions protocol/tool focused

## Quality Standards

- All links must point to official repositories or documentation
- Descriptions should be factual and unbiased
- Categorization should follow the existing tier system
- No affiliate links or promotional content
